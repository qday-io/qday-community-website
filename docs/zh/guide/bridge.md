# ABEL 跨鏈橋用戶指引

ABEL Bridge（[abel-bridge.qday.io](https://abel-bridge.qday.io)）是連接 Abelian 區塊鏈與 QDay 網路的官方跨鏈工具，讓您可以將 Abelian 網路上的 ABEL 代幣橋接並鑄造為 QDay 網路上的 wABEL（Wrapped ABEL）代幣，進一步參與 QDay DeFi 生態（質押、兌換等）。

:::tip 前置要求
開始之前，請確認您已備妥：
- 安裝並設定 [MetaMask 錢包](/zh/guide/metamask#下載-metamask-擴充程式)
- 安裝 **Abelian Pro** 行動錢包（iOS / Android），且持有足夠的 ABEL 代幣
:::

---

## 步驟 1：連接 MetaMask 錢包

1. 開啟瀏覽器，前往 [https://abel-bridge.qday.io](https://abel-bridge.qday.io)。
2. 在跨鏈橋頁面，點擊 **「連接錢包」** 按鈕。
  ![ABEL Bridge 首頁，點擊「連接錢包」](/qday/bridge/connect-zh.png)

1. 在彈出的錢包選擇視窗中，選擇 **MetaMask**。
2. MetaMask 會彈出連接請求視窗，確認您要連接的帳戶，點擊 **「下一步」**。
3. 在權限請求頁面，點擊 **「連接」** 按鈕，授權跨鏈橋訪問您的錢包地址。
4. 若您尚未在 MetaMask 中新增 QDay 主網，跨鏈橋可能提示您切換網路，點擊 **「切換網路」** 即可自動新增並切換。詳細步驟請參考 [MetaMask 錢包帳戶用戶指引 - 新增 QDay 網路](/zh/guide/metamask#新增-qday-網路到-metamask)。
5. 連接成功後，頁面頂部會顯示您的 QDay 錢包地址（例如 `0xfA...5AE1`）。
  ![已連接 MetaMask，頁面顯示錢包地址](/qday/bridge/connected-zh.png)

:::warning 注意
請確認 MetaMask 已切換至 **QDay** 主網，否則跨鏈橋可能提示您切換網路。
:::

---

## 步驟 2：填寫跨鏈資訊

### 2.1 輸入轉換金額與 ABEL 錢包地址

連接錢包後，頁面自動進入輸入詳情階段：

- **從** 區塊中填寫 ABEL 數量① 與 Abelian 錢包地址②
- 確認資訊無誤後，點擊底部的 **「生成二維碼」** 按鈕③
  ![填寫 ABEL 數量與 Abelian 錢包地址](/qday/bridge/input-abel-zh.png)

:::tip 提示
1. **從** 區塊：網路已預設為 **Abelian**，代幣為 **ABEL**；
2. **到** 區塊：網路已預設為 **QDay**，代幣為 **wABEL**。
  - **接收者** 欄位會自動填入目前連接的 MetaMask 錢包地址。
3. **備註（可選）**：可填寫備忘文字，不影響交易。
4. 請仔細核對 **Abelian 錢包地址**，輸入錯誤將導致轉帳失敗或資產遺失。
:::

### 2.2 使用 Abelian Pro 掃碼轉帳

1. 頁面進入 **掃描二維碼** 階段，並顯示操作說明與 QR Code：
2. 使用 **Abelian Pro 行動錢包** 的掃碼功能掃描頁面上的 **QR Code**①，確認金額與地址後完成轉帳。
3. 轉帳成功後，從 Abelian Pro 複製 **交易哈希（TXID）**，貼入頁面底部的「交易哈希」欄位②，然後點擊 **「我已完成轉帳」**③。
   ![掃描二維碼轉賬](/qday/bridge/scan-qrcode-zh.png)

:::warning 重要提醒
- 請務必使用跨鏈橋生成的二維碼進行轉帳，不要手動修改任何交易資訊。
- 確保備註資訊完整，否則可能導致跨鏈失敗。
:::

## 步驟 3：等待鑄造確認

### 3.1 等待 3 個區塊確認（鑄造 wABEL）

點擊「我已完成轉帳」後，系統進入 **確認中** 階段，頁面顯示 **「處理交易中」** 及圓形進度條：

- 進度顯示為 **1 / 3 → 2 / 3 → 3 / 3**，代表 Abelian 網路需要 **3 個區塊確認**。
- 系統同步顯示 **Abelian 交易高度** 與 **最新 Abelian 高度**，方便您追蹤進度。
![等待 Abelian 網路 3 個區塊確認](/qday/bridge/transaction-processing-zh.png)

:::tip 提示
每個 Abelian 區塊約需 2–3 分鐘，整個確認過程大約需要 **6–10 分鐘**，請耐心等待；
剛進入等待確認階段，頁面出現 “**Transaction not yet indexed**” 的提示，不用擔心耐心等待 3 個高度的時間；
若需停止監控，可點擊頁面底部的 **「停止監控」** 按鈕。
:::

### 3.2 跨鏈成功，完成 wABEL 鑄造

三個區塊確認完成後，頁面會顯示 **「跨鏈成功！」** 並呈現本次跨鏈摘要：

| 欄位         | 說明                                       |
| ------------ | ------------------------------------------ |
| **您收到**   | 本次鑄造的 wABEL 數量（例如：`+10 wABEL`） |
| **交易哈希** | 可點擊連結至 QDay 區塊鏈瀏覽器查看詳情     |
| **從**       | 您的 Abelian 錢包地址（縮寫）              |
| **到**       | 您的 MetaMask 錢包地址（縮寫）             |
| **之前餘額** | 跨鏈前的 wABEL 餘額                        |
| **新餘額**   | 跨鏈後的 wABEL 餘額                        |

![跨鏈成功頁面，顯示收到 wABEL 與交易摘要](/qday/bridge/success-zh.png)

完成後，您可以：
- 點擊 **「立即質押 wABEL」** 前往 [ABEL 質押](https://abel-staking.qday.io/) 頁面，立即開始賺取每日 QDAY 獎勵。
- 點擊 **「開始新跨鏈」** 發起下一筆跨鏈交易。

### 3.3 查看歷史跨鏈交易記錄

頁面底部的 **「最近交易」** 欄顯示目前連接錢包的所有跨鏈交易歷史，包括時間、金額及狀態，方便您追蹤每一筆跨鏈紀錄。
![查看歷史跨鏈交易記錄](/qday/bridge/history-zh.png)

## 常見問題

**Q：跨鏈大約需要多久？**
整個流程通常需要 **10–15 分鐘**：Abelian 網路確認（6–10 分鐘）＋跨鏈橋處理（1–2 分鐘）＋QDay 網路確認（1–3 分鐘）。

**Q：為什麼需要 3 個確認？**
Abelian 網路需要 3 個區塊高度確認以確保交易的安全性與不可逆性，這是跨鏈橋的標準安全機制。

**Q：如果超過 30 分鐘仍未收到 wABEL？**
1. 至 Abelian 區塊鏈瀏覽器確認交易已成功上鏈。
2. 確認您貼入的交易哈希正確無誤，並檢查備註資訊是否完整。
3. 在跨鏈橋的「最近交易」欄查詢跨鏈狀態。
4. 聯繫 QDay 技術支援，並提供您的交易哈希。

:::danger 安全提示
- 請務必從官方連結 [abel-bridge.qday.io](https://abel-bridge.qday.io) 進入，謹防釣魚網站。
- 仔細核對所有錢包地址，輸入錯誤可能導致資產**永久遺失**。
- 建議先以小額測試整個流程，確認順暢後再進行大額跨鏈。
- 保存好交易哈希，以便後續查詢和追蹤。
:::
